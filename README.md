## What it does

`main.py` writes exactly one word to `/output/entry.txt`: the entrant's own make.fun username, `ahmad-nur-rohim` — 15 characters, no spaces, no explanation, no pitch. That is the whole task: the judge compares usernames two at a time and picks the funnier or more interesting one, weighing first whether the text is the entrant's genuine handle. Any added word would stop being the handle, so nothing is added.

## Run

```sh
python3 main.py
cat /output/entry.txt
# ahmad-nur-rohim
```
